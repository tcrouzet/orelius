# Écrire avec Orelius

## Quel est votre point de départ ?

| Votre situation | Votre parcours |
| --- | --- |
| Vous avez une idée, quelques notes ou seulement l’envie de commencer. | [Démarrer un manuscrit](Demarrer.md) |
| Vous avez déjà des chapitres et voulez écrire la suite ou les retravailler. | [Continuer un manuscrit](Continuer.md) |
| Vous voulez transformer un texte existant ou reprendre une ancienne version selon une nouvelle direction. | [Adapter un manuscrit](Adapter.md) |

Chaque parcours explique où placer vos matériaux, quand cliquer sur **Peupler**, quelle demande envoyer et où retrouver le résultat. Vous n’avez pas besoin d’un manuscrit existant pour utiliser Orelius.

## Avant de suivre votre parcours

Dans **Réglages → Orelius**, vérifiez Codex puis choisissez le dossier du projet avec **Parcourir…**. Les dossiers de travail sont créés automatiquement lors de la préparation du projet. Les réglages sont enregistrés à la volée.

Les guides utilisent les noms par défaut : `Manuscript` pour le texte en cours, `Model` pour un texte source à adapter, `Bible` pour les personnages et les règles d’écriture. Si vous les avez renommés, utilisez vos propres noms.
