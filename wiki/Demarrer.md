# Démarrer un manuscrit

[Les trois parcours](Home.md)

**Vous partez d’une idée ou de notes. Aucun chapitre existant n’est nécessaire.** L’objectif est de choisir une direction puis d’écrire un premier passage.

## 1. Poser votre idée

Dans l’explorateur, faites un clic droit sur le dossier parent, choisissez **Nouveau projet Orelius** et nommez-le. Model peut rester vide. Ensuite, créez une note `Manuscript/Seeds/depart.md`. Écrivez ce que vous avez, même quelques lignes :

> Une femme revient vendre la maison de son père. Elle découvre qu’une personne continue d’y recevoir du courrier sous son nom. Je veux un récit à la première personne, tendu, sans explications surnaturelles.

Vous pouvez laisser les personnages, la fin et les étapes inconnus. `Seeds` est le carnet des idées de départ. `Manuscript/Chapters/` et `Model/` peuvent rester vides.

Si vous préférez partir du chat, utilisez **Envoyer** :

> Je veux commencer un roman à partir de cette idée : [votre idée]. Enregistre-la dans Manuscript/Seeds/depart.md. Indique séparément mes choix et les questions encore ouvertes. Ne rédige pas de chapitre pour l’instant.

## 2. Organiser les premières pistes

Pour utiliser Peupler, déposez vos idées dans une nouvelle note de Model, puis cliquez sur **Peupler** à côté du dossier **Model**. Il organise les matériaux disponibles en graines, synopsis, scènes, arcs et intrigues. Avec peu de matière, certaines fiches signaleront « Non établi dans les sources ». Vous n’avez pas à remplir tous les dossiers pour commencer.

Peupler n’invente pas à votre place les décisions qui manquent. Pour explorer plusieurs possibilités, utilisez **Envoyer** :

> Propose trois directions pour ce récit dans Manuscript/Variants. Pour chacune, donne le conflit central, le choix difficile de la narratrice et ses conséquences. Ne rédige pas encore de prose.

## 3. Choisir ce que vous voulez écrire

Lisez les propositions utiles et indiquez votre choix dans le chat :

> Je retiens la deuxième direction, mais la narratrice connaît déjà l’expéditeur. Enregistre ce choix dans la graine, puis prépare un synopsis et les scènes du premier chapitre. Les autres directions restent des variantes abandonnées.

Précisez les règles de voix dans `Bible/Style/Narration.md` : qui raconte, au présent ou au passé, ce que le narrateur sait, le registre souhaité. Vous pouvez aussi demander explicitement à Codex d’y enregistrer ces décisions avec **Envoyer**.

## 4. Écrire le premier passage

Créez ou ouvrez `Manuscript/Chapters/001.md`. Dans le chat, utilisez **Envoyer** :

> Rédige l’arrivée dans la maison à partir de la direction retenue et des scènes préparées. La narratrice découvre une enveloppe récente portant son nom ; elle décide de l’ouvrir. Respecte Narration.md et arrête le passage à ce choix. Enregistre dans Manuscript/Chapters/001.md.

Le résultat se trouve dans la note du chapitre. La préparation et les sources restent dans `Manuscript/Context/001/`. Vous n’avez pas à lire les documents techniques avant de lire le texte.

## 5. Poursuivre

Lisez le passage puis suivez le cycle [relire, Réviser, Accepter](Travailler.md). Une fois le premier chapitre écrit, vous pouvez suivre [Continuer un manuscrit](Continuer.md).
