# Livres d’exemple

Déposer ici les fichiers `.epub` à présenter sur le site public. Les sous-dossiers sont acceptés. Le catalogue est généré automatiquement ; les autres fichiers ne sont pas publiés. Les liens symboliques sont refusés.

`exemple.epub` est un court guide de démonstration du lecteur. Il peut être supprimé ou remplacé par un livre.

Après un ajout ou un retrait, pousser les modifications sur `main` reconstruit et publie le site avec GitHub Actions. Publier uniquement des livres dont la diffusion est autorisée.
